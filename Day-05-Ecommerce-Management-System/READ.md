# Day 5 - E-Commerce Management

## Overview

This project demonstrates intermediate MySQL concepts through an E-Commerce Management database.

The project focuses on customer and order data while combining previously learned SQL concepts with the new `CASE` expression for conditional classification and reporting.

## Concepts Covered

* CREATE DATABASE
* CREATE TABLE
* INSERT
* SELECT
* WHERE
* ORDER BY
* DISTINCT
* LIKE
* BETWEEN
* Aggregate Functions
* GROUP BY
* HAVING
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* UPDATE
* DELETE
* Subqueries
* Correlated Subqueries
* Views
* Indexes
* CASE Expression
* CASE + Aggregate Functions
* CASE + GROUP BY
* CASE + JOIN
* Business Reporting Queries

## Key Practice

The project includes practical queries for:

* Customer and order analysis
* Order value classification using `CASE`
* High, Medium and Low value order classification
* Customer spending classification
* Category-wise revenue analysis
* Customer-wise order and spending reports
* Subqueries and correlated subqueries
* Views and indexes
