# Day 4 - Hospital Management System

## Overview

This project demonstrates intermediate MySQL concepts through a Hospital Management System. It focuses on managing doctors and patients while reinforcing SQL fundamentals learned in previous projects and introducing Indexes for query optimization.

## Database Tables

* Doctors
* Patients

## Concepts Covered

* CREATE DATABASE
* CREATE TABLE
* INSERT
* SELECT
* WHERE
* ORDER BY
* DISTINCT
* Aggregate Functions
  * COUNT()
  * SUM()
  * AVG()
  * MAX()
  * MIN()
* GROUP BY
* HAVING
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* UPDATE
* DELETE
* Subqueries
* Views
* Indexes

## Business Scenarios Practised

* Patient and doctor management
* Disease-wise analysis
* Hospital revenue analysis
* Doctor-wise patient count
* Patients treated by specific specialists
* Revenue analysis using aggregate functions
* View creation for reporting
* Index creation for faster searching
